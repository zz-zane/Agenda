# Agenda desktop pet

Single-click opens Agenda's themed Today panel, listing today's unfinished tasks in time order with the existing daily photo upload and check-in actions. Double-click still opens AI; dragging does not open either panel. A short click delay uses the Windows double-click setting to distinguish these gestures. After waking voice with “你好”, “打开今日待办表” (including common “代办” spelling) opens the same panel locally without calling the model. Photos/check-ins remain per-day, not per-task.

Reuses the user's MiaoDesk Windows MVP v0.1 `pet_window.py` and four cat sprite sheets. The Agenda copy keeps its existing poses, transitions, dragging and sleep animation. The sole animation-module adaptation replaces NumPy color-key masking with equivalent Pillow operations, using Agenda's existing dependency.

`desktop_pet.py` supplies the Agenda menu and private pipe events. Double-click opens the existing AI page. Optional voice reuses MiaoDesk's `local_voice.py` and `wake_voice.py`: local “你好” wake detection, SenseVoice recognition, AISHELL3 speech, 174 speaker choices, renewable 10-second sessions and wake-word interruption during reply playback. Text goes through Agenda's current model; previews still require the existing confirmation button. Existing text drafts are preserved. No second chat database or cloud audio credentials are used. Enablement, speech preference, speaker and microphone threshold are saved with appearance settings. New installations default to disabled; disabling the pet closes voice too.

The model weights are local build inputs under ignored `agenda_pet/models/`, not Git source files. This integration reuses the existing MiaoDesk model installation: `sensevoice` (model.int8.onnx, tokens.txt, LICENSE), `vits-icefall-zh-aishell3` (model.onnx, tokens.txt, lexicon.txt, phone.fst, date.fst, number.fst), and `sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20` (tokens plus the chunk-16 encoder/joiner int8 and decoder ONNX files). Copy only these files into their corresponding subdirectories before building. Keyword text is in `assets/dada-keywords.txt`. Install the pinned build requirements; the Windows build bundles runtime DLLs and models. Do not copy original app settings or credentials.

Audio stays local; recognized commands become chat text. This is not speaker authentication or acoustic echo cancellation. Background media can trigger the common greeting; headphones reduce playback feedback. Closing voice releases the input stream; closing Agenda ends the pet process even during audio work.

Checks: `py -3.13 -m unittest discover -s tests -p test_desktop_pet.py` and `node scripts/check-desktop-window.mjs <Agenda.exe> --pet`. The Python check exercises real Tk sprites and the double-click action callback, not physical mouse input. The packaged check covers enable/disable, persisted startup and parent-owned exit. Existing frozen AI runtime checks remain separate.

Voice checks: `py -3.13 -m unittest discover -s tests -p test_voice_bridge.py`; add `--voice` to the packaged `--pet` check for settings, synthetic speech-to-chat routing, draft preservation, audible local preview and microphone start/stop. Synthetic events and model samples do not establish human-microphone recognition quality or real-provider conversation quality.
